# PassGen — Python Password Generator

A beginner-friendly desktop password generator using Python and Tkinter.

## Features
- Adjustable password length (8–40 characters)
- Select uppercase, lowercase, digits and symbols
- Secure random generation using Python's secrets module
- Copy to clipboard
- Dark theme

## Run in VS Code
Open this folder and run `python main.py` in the terminal. Python 3 with Tkinter is required. Check Tkinter with `python -m tkinter`. No pip packages are needed.

Passwords are not saved by the application. Clipboard contents may remain accessible to other applications; clear the clipboard after use when appropriate.

## Concepts
Functions, lists, loops, conditionals, standard library modules and GUI events.
